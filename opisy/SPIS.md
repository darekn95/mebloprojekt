# Jak działa program — zwięzłe opisy

Krótkie opisy zasad, według których program liczy poszczególne części mebla.
Do czego służą:
- przy poprawkach — żeby było wiadomo, jak coś działa i co zmiana ruszy;
- przy pytaniach — szybka odpowiedź bez szukania po kodzie.

Każdy opis ma te same części:
1. **Co program liczy sam** — wartości „auto” i domyślne.
2. **Co ustawiasz ręcznie** — pola w interfejsie.
3. **Kontrole** — błędy (×), ostrzeżenia (!), informacje (i) i przyciski poprawek w Uwagach.
4. **Skąd liczby** — katalog z `instrukcje/` albo decyzja użytkownika (data, wpis w `BLEDY.md` „Ustalone”).
5. **Gdzie w kodzie i testy** — skrót. Szczegóły (pole → dane → funkcja) są w `SLOWNIK.md`.
